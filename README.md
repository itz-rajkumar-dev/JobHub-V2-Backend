# JobHub V2 Backend

A microservices-based job portal backend built with Spring Boot.

## Architecture
- Spring Boot microservices
- Spring Cloud Eureka Service Discovery
- Spring Cloud Config Server
- API Gateway
- JWT-based authentication
- Apache Kafka for event-driven notifications
- Multiple database integrations

## Project Status
Under development.

## Configuration
Provide database credentials, JWT secrets, Cloudinary credentials, and mail credentials through environment variables. Never commit real secrets or the local .env file.

## Run
Configure environment variables and the required infrastructure before starting the services.
